# Orbyn contributor entry point

Read [AGENTS.md](AGENTS.md), the single canonical repository policy.
It routes to the development, UI, operations, delivery and skill guides.
This compatibility entry point remains for existing links and clients.

For engineering work, use [the named agents and workflow roles](docs/agents/roles.md).
[Model policy](docs/agents/model-policy.md) owns selection and authority;
[the shared model registry](docs/agents/models.json) owns both providers' current
model and effort values. Follow [coordination](docs/agents/coordination.md) for
lead delegation and [development](docs/agents/development.md#branch-naming) for
new branch names. This entry point does not define competing defaults.
