## Official contract boundary (checked 8 October 2026)

The [OSS plan guide](https://developers.openai.com/siwc/token-sharing-open-source)
allows automatic first registration using `dynamic_agent_client`. The issued ID
belongs to the verified user/workspace; a preregistered application ID is not needed
for this local flow. It requires a local `127.0.0.1` callback and protected runtime
credentials, not browser storage.

The same guide directs paid/remotely hosted applications to an interest form.
The [website guide](https://developers.openai.com/siwc/website) describes a separately
provisioned, identity-only partner flow; identity does not authorize plan inference.
A hosted callback must not be substituted into the OSS loopback flow.

[Accounts and sessions](https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions)
documents rotating refresh, remote revocation and the ChatGPT usage settings link.
It does not provide a general account-quota endpoint. Orbyn must label its own
measurements separately. Verified grant permission is distinct from a verified
subscription-tier claim; unavailable tier/allowance remains unknown.
