# OpenAI DevDay 2026 → Orbyn implementation contract

Updated 30 September 2026 after the user authorized implementation and revised the scope.

The governing plan is [DevDay implementation review](reviews/devday-2026-implementation-review.md). The accepted architecture is [ADR 001](adr/001-devday-agent-platform.md).

Retained scope: eligible ChatGPT sign-in and plan runtime; managed/BYO provider compatibility; account-specific `/models` catalog and default selection; supported model/caching controls; typed rules and agent ownership/activity/budgets; maintained pages and publication; authorized notification channels; a separate plugin backend integration; Markdown visualization/preview/export parity and cross-client UI synchronization; access-gated security scanning.

Voice, computer use and the speculative Decisions integration are excluded. Implementation is incomplete; checkpoints require current production-readiness evidence before main integration.

The original research is preserved as [historical evidence](reviews/archive/openai-devday-original-2026-09-30.md), not as the current delivery scope.
