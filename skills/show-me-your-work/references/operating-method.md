# Leave an evidence trail another maintainer can follow

Use the existing task record, or a separate single-writer TSV per worker. Record decisions that change ownership, compatibility, verification or delivery; omit routine tool chatter. Keep payloads and credentials out of evidence logs.

A useful checkpoint names candidate revision, decision, reason, artifact/receipt and actual outcome. Distinguish prepared, attempted, failed, observed and externally delivered. When a conclusion changes, add a superseding record instead of deleting the failed attempt.

For a schema cutover, preserve the old-reader compatibility decision, the writer-fencing evidence, batch outcome and remaining operator action. A command transcript without its terminal result does not establish success. Link durable artifacts from a committed report only when that report is in publication scope.

Before delivery, open the cited artifacts and reconcile the trail with the final candidate. Report missing receipts and unexecuted checks. The log is supporting evidence, not a substitute for inspecting the result or independent qualification.
