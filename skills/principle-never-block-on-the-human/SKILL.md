# Principle never block on the human

Follow the consuming project's instructions first. Use [Orbyn Engineering policy](../../AGENTS.md) and [host/model guidance](../../docs/agents/model-policy.md) where applicable; load only relevant references.

Make routine choices from context, state consequential assumptions and present a reviewable result. Ask only for missing intent, authority or a preference that matters. Continue independent work while waiting. Silence is not consent; existing authorization persists. Never infer permission for external messages, global settings or production changes from autonomy language.

## Decision in practice

Is the missing answer actually required for this next effect?

Prepare and validate a migration or public export before asking for its final consequential action. Continue independent documentation while a product choice is pending. Do not treat the elapsed wait as approval or turn an ordinary implementation detail into an approval request.

## Apply and hand off

Classify a missing answer as routine implementation choice, consequential preference or authority for an effect. Continue work whose correctness does not depend on that answer.

Concrete check: Prepare the exact public patch and checks while a publication decision is pending. Elapsed time does not authorize pushing it.

Return the changed invariant, its owning location and the observation or evidence
gap. Carry execution through [orbyn-plan](../orbyn-plan/SKILL.md) when relevant. This
principle refines that task; it does not create another mandatory phase.
