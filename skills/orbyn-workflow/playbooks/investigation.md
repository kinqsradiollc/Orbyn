# Read-only investigation

The lead owns the answer. Identify the question and source/target; use `how` for
source mechanics, `why` for rationale or REA for shipped artifacts.

For substantial investigation, identify independent slices in a short throughput
checkpoint and delegate bounded questions to named Investigators under the parent
[workflow](../SKILL.md). One investigator is sufficient for a coupled path; narrow
questions and children assigned a slice proceed directly.

Inspect the returned source evidence, reconcile contradictions and verify decisive
claims against the actual source or authorized runtime evidence. Collect only what
answers the question. Return observations, inference and unknowns in the lead's
own explanation. Do not implement during an explanation-only request.
