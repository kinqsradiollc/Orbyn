# Autonomous run

Define completion and checkpoints. Use the parent [workflow](../SKILL.md) for lead
ownership, bounded delegation, artifact review and authorized verification. Keep a
concise decision trail and bounded retries with meaningful progress updates.
Children execute their owned tasks directly and return evidence; the lead routes
corrections and assesses completion.

For separately requested project sessions, follow
[coordination](../../../docs/agents/coordination.md). Do not infer permission for
recurring schedules or new sidebar chats. Respect explicit pauses and unresolved
authority. Autonomy does not expand testing or delivery scope.
