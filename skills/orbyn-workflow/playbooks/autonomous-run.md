# Autonomous run

Define completion and checkpoints. Continue authorized work with a concise decision trail, bounded retries and meaningful progress updates. Use bounded subagents for supporting work. For separately requested project sessions, follow [coordination](../../../docs/agents/coordination.md). Do not infer permission for recurring schedules or recursively create sessions. Respect explicit pauses and unresolved authority.

Use the parent [workflow](../SKILL.md) and repository scope.
