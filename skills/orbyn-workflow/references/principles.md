# Select a principle

Load only the leaf relevant to a current decision. These are maintained Orbyn principles. Source attribution is recorded separately
in the tooling notices.

- [boundary discipline](../../principle-boundary-discipline/SKILL.md): Design validation and error handling at real trust or effect boundaries.
- [build the lever](../../principle-build-the-lever/SKILL.md): Choose reusable automation for repetitive or fragile work.
- [encode lessons in structure](../../principle-encode-lessons-in-structure/SKILL.md): Prevent a demonstrated recurring error at its owning boundary.
- [exhaust the design space](../../principle-exhaust-the-design-space/SKILL.md): Resolve a consequential unfamiliar design choice by comparing concrete alternatives.
- [experience first](../../principle-experience-first/SKILL.md): Resolve product trade-offs around the person completing the task.
- [fix root causes](../../principle-fix-root-causes/SKILL.md): Trace a defect to the owner of the invalid state or interpretation.
- [foundational thinking](../../principle-foundational-thinking/SKILL.md): Choose data shape, ownership and lifecycle before adding logic.
- [guard the context window](../../principle-guard-the-context-window/SKILL.md): Keep investigation context useful during large searches and long tasks.
- [laziness protocol](../../principle-laziness-protocol/SKILL.md): Simplify a design or diff without losing required behavior.
- [make operations idempotent](../../principle-make-operations-idempotent/SKILL.md): Design commands and workers that tolerate retries, crashes and duplicate delivery.
- [migrate callers then delete legacy apis](../../principle-migrate-callers-then-delete-legacy-apis/SKILL.md): Replace an internal API while eliminating duplicate old paths.
- [minimize reader load](../../principle-minimize-reader-load/SKILL.md): Reduce indirection and hidden mutable state in difficult-to-follow code.
- [never block on the human](../../principle-never-block-on-the-human/SKILL.md): Continue authorized reversible work without unnecessary confirmation.
- [outcome oriented execution](../../principle-outcome-oriented-execution/SKILL.md): Complete an agreed migration without accumulating temporary compatibility debt.
- [prove it works](../../principle-prove-it-works/SKILL.md): Match a completion claim to direct evidence about the requested artifact.
- [redesign from first principles](../../principle-redesign-from-first-principles/SKILL.md): Integrate a new requirement into a coherent design instead of layering patches.
- [separate before serializing shared state](../../principle-separate-before-serializing-shared-state/SKILL.md): Prevent concurrent writers from corrupting a shared artifact or state object.
- [sequence verifiable units](../../principle-sequence-verifiable-units/SKILL.md): Order a multi-part change so failures are localized and delivery is understandable.
- [subtract before you add](../../principle-subtract-before-you-add/SKILL.md): Reduce existing complexity before extending an affected design.
- [type system discipline](../../principle-type-system-discipline/SKILL.md): Use types to express valid states and prevent meaningful contract mistakes.
