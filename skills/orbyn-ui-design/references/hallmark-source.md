## Disposition

| Material | Decision and local owner |
| --- | --- |
| Task/material-first composition, specific direction, coherent tokens | Adapted into visual direction, with existing project design authority retained |
| Before/after behavior inventory and change depth | Adapted into redesign contract; behavioral verification supplements structural counts |
| Interaction states, honest completion, brand/asset evidence | Adapted with applicable-state selection and existing UI/backend contracts |
| Accessible focus, responsive layouts, reduced motion, truthful facts | Already covered; connected to existing design rules rather than duplicating another checklist |
| Theme catalog, layout randomization, fixed heroes/section counts, blanket style bans | Not imported: unsuitable as universal application/native design rules |
| Scripts, hooks, browser automation, global installation, providers and image generation | Not imported or executed; use supported host tools and project checks |
| Photos, fonts, screenshots and other assets | Not imported; each asset retains its own licensing requirements |
| Mandatory questions, clean-tree demand, automatic reviews/fanout and CSS stamps | Not imported; user scope, bounded delegation, project conventions and artifact lifecycle remain authoritative |

Raw downloaded text/scripts stay under ignored `orbyn-references/hallmark/`.
Only these maintained methods, this source record and the original license enter
the public library. This is a selected guidance adaptation, not a vendored or
validated Hallmark installation. The source review does not qualify its scripts.
