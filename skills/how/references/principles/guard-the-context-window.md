# Guard the context window

Search narrowly, cap output and read only relevant sections. Keep file pointers and compact evidence summaries. The lead delegates genuinely independent bulk analysis under [coordination](../../../orbyn-workflow/references/project-policy.md#delegation-and-host-configuration) with a small brief; assigned children analyze their own slice directly. Do not clone the entire conversation by default. Do not reread unchanged files or load every skill reference.

## Decision in practice

What information will the next decision actually need?

For a cross-client change, retain schema and entrypoint pointers, the candidate revision and a short unresolved-risk list. Read the owned caller slices rather than dumping every client. A compact handoff must still identify excluded files and failed checks, not just the preferred conclusion.

## Apply and hand off

Keep a candidate, decisive file/symbol pointers, unresolved question and failed-check references. Read the smallest slice that can resolve the next question.

Concrete check: Summarizing a migration must retain the old-writer exclusion and missing cutover receipt. Dropping those details saves context while making the handoff false.

Return the changed invariant, its owning location and the observation or evidence
gap. Carry execution through [how](../../SKILL.md) when relevant. This
principle refines that task; it does not create another mandatory phase.
