# Orbyn-owned project skills

This directory belongs to the Orbyn consumer, outside public skill sync.
Future product/repository-only skills belong at
`orbyn/orbyn-<skill-name>/SKILL.md`, with matching namespaced frontmatter and
both host links. Portable methods stay in the shared `skills/` tree.

Follow the [ownership/migration guide](../skills/orbyn-setup/references/project-skills.md).
The agent classifies ownership, migrates clear owned material with backups and
runs local discovery and public pin checks. Existing product guides keep their
owners; no company-only skill is invented just to populate this folder.
